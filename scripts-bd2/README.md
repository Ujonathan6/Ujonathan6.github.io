Scripts de las clases, talleres y practicas de Bases de Datos 2 (Universidad El Bosque).
El analisis, el contexto y lo aprendido de cada tema estan en el portafolio:
https://ujonathan6.github.io/evidencias

| `02-plsql/` | Bloques anonimos, %ROWTYPE, cursores explicitos y excepciones |
| `03-nosql-mongodb/` | Notas de operadores MQL, patrones de datos NoSQL y ETL/DWH |
| `05-practica-nueva/` | Ejercicios adicionales de SQL, PL/SQL y MongoDB |
